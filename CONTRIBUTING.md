# 🤝 Contributing to NetHarvest

Thank you for your interest in contributing! Here's how to get started.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/Net_Harvest.git`
3. Install dependencies (see [README](README.md#-quick-start))
4. Create a feature branch: `git checkout -b feature/your-feature-name`
5. Make your changes
6. Push and open a Pull Request

## Code Style

- **TypeScript** everywhere — no plain `.js` files in `src/`
- Use `async/await` over callbacks
- Keep functions small and focused
- Add JSDoc comments to all exported functions

## Reporting Bugs

Open an issue with:
- Steps to reproduce
- Expected vs actual behaviour
- Any error messages from the browser console or backend terminal
